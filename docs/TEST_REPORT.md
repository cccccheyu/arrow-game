## 一·补、附加边界测试（T07~T08）

> 作业只要求 T01~T06。以下两项为**自加的边界与异常测试**，用于验证"极端输入不会让游戏崩溃"。

| 编号 | 测试内容 | 预期结果 | 实际结果 | 是否通过 | 验证方式 |
|:---:|---|---|---|:---:|---|
| **T07** | 最小边界：空棋盘 / 单箭头 / 1xN·Nx1 细长棋盘 | 空棋盘上任意格都不可点击，`free_arrows` 为空、`solve` 返回空解；单个箭头四个方向都能飞出；细长棋盘不越界 | 全部符合预期：空盘 `is_empty()=True`、`remaining_idle_count()=0`、`to_layout()` 全为 `.`；单箭头四方向 `can_shoot` 均为真且无阻挡物；1x5 / 5x1 / 1x1 棋盘均正常 | ✅ | `TestT07EmptyBoard` 6 个 + `TestT07SingleArrow` 6 个用例 |
| **T08** | 非法输入与越界防御 | 非法尺寸/空布局/行宽不一致/非法方向字符必须在构造期报错；越界坐标安全降级不崩溃；快照尺寸不匹配报错 | 全部符合预期：`Board(0,3)`/`Board(-1,3)`/`from_layout([])`/`from_layout(["...",".."])`/`from_layout(["x.."])` 均抛 `ValueError`；`get`/`remove` 越界返回 `None`，`can_shoot` 越界返回 `False`；`restore` 尺寸不匹配抛 `ValueError` | ✅ | `TestT08IllegalSize` 6 个 + `TestT08OutOfRangeDefense` 6 个 + `TestT08StateBoundary` 4 个用例 |

**为什么加这两项**：路径检测的正确性已经在 T01~T03 验证过，但**输入的合法性**和**极端局面**没有覆盖。实际试玩时出现过「动画中连点导致状态错乱」的情况，因此专门补测了 `can_shoot` 对非 `IDLE` 状态（`FLYING`/`SHAKING`/`GONE`）的拦截，以及"已消除格子再点一次不会重复计分"。

## 六、运行测试的命令

```bash
# 运行全部测试
python -m unittest discover -s tests -v

# 运行单个测试文件
python -m unittest tests.test_path_check -v
python -m unittest tests.test_levels -v
python -m unittest tests.test_save -v
python -m unittest tests.test_edge_cases -v

# 验证所有关卡可解性
python -c "
from arrow_game.level import LEVELS
from arrow_game.solver import solve
for lv in LEVELS:
    b = lv.build_board()
    sol = solve(b)
    print(f'L{lv.id}: {\"OK\" if sol else \"FAIL\"}')
"
```
